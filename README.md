# Civic Connect Bangladesh

Here's a prompt you can paste directly into Lovable. It focuses only on the UI/UX, not backend logic.





---



Prompt



I want you to design a premium, modern civic platform UI called Protidhwani (প্রতিধ্বনি).



Do not build an AI chatbot. This should not look like ChatGPT, Discord, Reddit, X, or Facebook. Take inspiration from social platforms, but create an original visual identity.



The platform is a citizen powered civic network for Bangladesh where people can discuss issues, report incidents, verify information, request emergency help, protect rights, and organize communities.



Typography



I will attach a Bangla font named Li Noirit.



Use this font for every Bangla text.



Every piece of content must follow this format:



Bangla English



Example



প্রতিধ্বনি Protidhwani



অভিযোগ জানান Report Incident



জরুরি সহায়তা Emergency Help



Bangla should always be visually dominant. English should appear below using a smaller font size.





---



Design Language



Create a completely original design.



Avoid:



• AI chatbot layouts • Messenger layouts • Facebook clone • Discord clone • Reddit clone



Instead create something that feels like:



Government grade Community driven Modern Minimal Premium Trustworthy



Think of Notion, Linear and Arc Browser quality combined with civic technology.
